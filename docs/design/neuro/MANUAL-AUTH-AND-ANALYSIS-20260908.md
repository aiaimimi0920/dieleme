## 1. 主动认证逻辑

原来的 [总览渲染](C:/Users/Public/nas_home/crow/collector-desktop/src/desktop_overview.ts) 使用 `challenge !== true` 禁用认证按钮。这会同时禁止“无挑战”和“挑战状态未知”时的主动认证，与用户要求相反。

现已移除这个条件，保留挑战状态本身的显示。以下情况都可以打开认证弹窗：

- PC2 正在挑战中；
- PC2 没有报告挑战；
- 挑战状态未知；
- 采集处于人工暂停状态。

交互仍然只有两个按钮：

1. **打开挑战页面**：打开专用 PC1 浏览器页面，由用户完成官方人工认证。
2. **已完成挑战**：验证当前页面会话，发布认证快照及元数据，走现有 PC1 → NAS → PC2 恢复链路。

仅打开弹窗不会提交任务、暂停采集或导出 Cookie。已有快照正在同步时，仍然查询原任务，不重复发布或抢占现有恢复任务。认证凭据、目标页面身份、陈旧挑战检查和并发保护保持不变。

NAS 的 `request_manual()` 本来就支持无需等待自动挑战/停滞的人工恢复，因此本次不需要修改或部署 NAS 后端。新增回归覆盖了空挑战 ID 时的请求接受、快照发布、PC2 领取和最终增长确认；这是离线合成数据验证，并未代替用户在真实站点认证。

## 2. 为什么商品分析不增长

### 当前采集不是所有阶段都完全停止

只读 NAS 状态样本：

| 北京时间 | 已采详情 | 已完成 AI 归档 | 待分析 | 分析处理中 |
| --- | ---: | ---: | ---: | ---: |
| 03:34:22 | 108075 | 79342 | 27376 | 0 |
| 03:37:07 | 108095 | 79342 | 27396 | 0 |
| 03:57:42 查询 | 108145 | 79342 | 27446 | 0 |

前两次样本实际间隔约 165 秒。最后一次查询显示：链接阶段 `seed.manual_required=true / paused=true`，详情阶段 `detail.paused=false`。因此链接确实遇到人工挑战，但详情仍有间歇增长，不能仅凭总览“待认证”判断全部 worker 都停止。

### 分析有大量输入，但在模型预检处停止领取

PC2 的四个 `fapaifang-pc2-analysis-1` 至 `-4` 容器均在运行，健康检查通过，实际版本为 `20260908-modelpool-r3`。近期日志反复出现：

```text
decision = detail_worker_llm_unavailable
attempts = 0
completed = 0
sleep_seconds = 60
```

[分析 batch](C:/Users/Public/nas_home/crow/tools/detail_worker_loop.py) 在模型预检不可用时直接返回，不领取商品。这个保护避免浪费商品重试次数，不应为了让数字动起来而删除。

[分析专用路径](C:/Users/Public/nas_home/crow/tools/detail_worker_execution.py) 从已抓取的原始详情领取任务，没有链接采集的挑战暂停门槛。待分析队列超过 2.7 万条，也排除了“没有原始详情可分析”的解释。

### 动态发现正在运行，但目录中的模型没有成功返回

对 PC2 私有模型资格文件 `/data/datas/model-pool/pool.sqlite3` 进行只读检查，得到一次完整摘要：

- 已测试模型路由：**169**。
- 合格模型：**0**。
- 成功返回答案的测试案例：**0 / 845**。
- 失败分布：HTTP 403 × 80、503 × 343、408 × 255、429 × 52、读取超时 × 114、404 × 1。

**这不是模型答错题后被严格评分淘汰，而是测试请求没有拿到答案。** 动态目录发现、分批测试、五例精确评分和 GPT 排除已经存在，继续增加目录数量并不能把失败路由变成可调用模型。本次也复跑了模型池分批继续扫描与新模型优先测试的回归，不需要再添加一套重复的发现流程。

当前分析请求指向本机的 `http://192.168.15.20:8317/v1`，由 CLIProxyAPI 提供。只读核验确认实际监听进程存在；但现有日志没有这些调用的上游错误正文。因此目前能够确认的失败边界是 **AI 服务生成请求不可用**，尚不能进一步断言全部是额度耗尽、密钥过期、模型权限或网络故障。HTTP 状态码和目录 HTTP 200 都不足以证明具体原因或真实生成能力。
