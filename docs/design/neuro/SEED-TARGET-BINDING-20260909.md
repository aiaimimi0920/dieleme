## 找到的代码缺陷

NAS 在创建人工恢复任务时只比较 `challenge_id`，没有将提交的列表 URL 与该挑战的实际采集 URL 绑定。PC2 随后验证提交的 URL，NAS 接收回执时也仅检查恢复任务内部的 URL 一致性。

因此，同一个挑战 ID 下，验证默认列表页就可能解除具体地区、排序和页码对应的暂停。离线回归已复现这个缺陷。历史认证记录与当前任务目标不同，也说明仅凭那条默认列表成功记录不足以确认实际地区任务恢复。

这项缺陷与当前新挑战都已取得证据；现有历史日志不足以还原每一轮空列表响应的原文，也不能证明修正目标后站点必然不再要求认证。
